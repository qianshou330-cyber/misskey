# PUBO 私信核心体验

本次增强仅用于站内一对一私聊：引用回复、本人置顶（最多10个）、本人免打扰。原有编辑、撤回、已读、语音及受保护附件流程继续使用。

引用只存原消息ID，不复制正文或附件。预览取当前内容，撤回显示墓碑；上下文读取与预取不标记已读。仅允许同一对话引用，失败重试保留发送标识、正文和引用ID。

置顶独立分页且新置顶在前。免打扰保留真实未读与灰色会话角标，过滤私信总角标并抑制声音、弹窗和已有网页推送；不影响收发、不自动已读、关闭后不补发旧通知。设置仅本人可见并通过本人事件同步设备。

## 接口与迁移

- `chat/conversation-settings/show` / `update`：本人对指定用户的`pinnedAt`、`isMuted`。
- `chat/conversations`：可选`pinned`筛选，省略保持原顺序。
- `chat/messages/create-to-user`：可选`replyToId`；未引用消息保留旧去重规则。
- `chat/messages/context`：本会话目标及前后最多各20条，无读取回执。
- `chat/unread-summary`：原真实未读字段不变，新增`notificationUnreadCount`和`hasNotificationLegacyUnread`供提醒入口使用。
- `1792627200000-chat-daily.js`：追加消息引用ID、通知抑制标记及本人会话设置表，不修改历史迁移或数据库/Redis服务配置。

## 发布与回退

发布需通过隔离数据库迁移往返、真实HTTP/WS、前端类型/构建、手机尺寸深浅主题和附件回归检查。完整证据保存在对应发布材料中；真实手机触摸、键盘、录音及真实账号验证未完成前，不声称全面验收通过。

生产回退使用本次专门准备的兼容镜像：保留新后端、新数据和免打扰约束，恢复旧前端交互。不得直接退回不认识免打扰状态的旧后端，不在生产执行新增迁移的`down()`。网站更新即可生效，无需重新打包APK。
